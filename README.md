# 🎠 ToyWonder

A vibrant and interactive toy store landing page designed to feel playful, modern, and magical. ToyWonder brings together smooth animations, responsive sections, and a polished shopping experience in a single-page website.

## ✨ Highlights

- Bright and colorful UI inspired by joyful childhood experiences
- Responsive layout for desktop and mobile devices
- Animated hero section and floating visual elements
- Product cards with interactive filters and cart actions
- Promotional countdown and newsletter signup experience
- Smooth scrolling and elegant visual transitions

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Open the project folder.
2. Double-click [index.html](index.html) to view it in your browser.

## 🌟 Project Goal

ToyWonder showcases a creative front-end design for an online toy store, combining storytelling, interactivity, and polished UI in one experience.
